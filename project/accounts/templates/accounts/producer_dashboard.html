How to use this page

This page shows orders that need action from this producer only. Click an order row to see customer details, products, delivery or collection information, and the next available status update.

How to use the order management page
1. Finding orders

Use the Filter button to find orders by status, order ID, customer name, or due date. Clear Filters resets the list back to the normal view.

2. Viewing an order

Click one order row to see the customer contact details, address, item list, special instructions, and current producer status.

3. How orders are sorted

Orders are shown by due date. The orders due soonest appear at the top of the list.

Producers should normally start from the top of the table and work downwards. Orders with an earlier due date should be checked first because those customers are expecting delivery or collection sooner.

If filters are used, the list still keeps the same due-date order, but only matching orders are shown.

4. Changing status

After selecting an order, use Change Status. Only the next allowed status will appear. The system will not show older statuses after the order has moved forward.

5. Cancelling item quantities

Use Cancel quantity when only part of an item cannot be supplied. Example: if 2 out of 3 items expired, cancel quantity 2 and prepare the remaining 1.

6. Cancelling a whole item

Use Cancel whole item when none of that specific item can be supplied. The rest of the producer order can still continue.

7. Cancelling the whole producer order

Use Cancel producer order and refund customer only when none of this producer's active items can be fulfilled. This cancels this producer section and refunds the customer for this producer section.

8. Delivery order stages
  1. Pending: order received, not started yet.
  2. Preparing: items are being prepared.
  3. Packaged: items are packed.
  4. Shipped: delivery has left the producer.
  5. Completed: delivery has been fulfilled.
9. Collection order stages
  1. Pending: order received, not started yet.
  2. Preparing: items are being prepared.
  3. Packaged: items are packed.
  4. Ready for collection: customer can now collect the order.
  5. Completed: customer has collected the order.
10. Mistakes

If a status is updated or an item is cancelled by mistake, contact an admin. Status should not be moved backwards because the order history must stay accurate.
